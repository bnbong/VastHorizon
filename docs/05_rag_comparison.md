# 05. RAG 전후 품질 비교 (F2015)

> 같은 질문을 **근거 없이** 답하게 한 결과와 **RAG(근거와 함께)** 로 답한 결과를 나란히 비교한다.
> 질문은 기획안 7장 '근거가 필요한 질문' 8개다.

---

## 1. 비교 방법

```mermaid
flowchart LR
    Q["질문 (기획안 7장)"] --> B["RAG 없이<br/>같은 모델 · 말투 · 길이<br/>근거 문서 없음"]
    Q --> R["RAG<br/>문서 수집 → 색인 → 검색<br/>→ 인용 검증 답변"]
    B --> J["근거 문서와 대조해 판정"]
    R --> J
```

| 항목 | 내용 |
|---|---|
| RAG 없이 | 같은 모델 · 말투 · 길이(3~6문장)로, 근거 문서만 빼고 묻는다 (`prompts.BASELINE_SYSTEM`) |
| RAG | 서비스 질의응답 전체 — 위키 문서 수집 · 색인 · 검색 · 인용 검증 · 재생성 |
| 판정 | 답의 주장을 RAG가 수집한 근거 문서와 하나씩 대조 (사람 판정) |
| 원본 기록 | `data/eval/rag_comparison.json` — 문항마다 실행 정보 · 원본 응답 · 표시용 응답 |
| 다시 보기 | Streamlit 검증 페이지 'RAG 전후 비교' 탭 — 질문별로 나란히, 실행 조건 함께 표시 |

> 차이가 '근거의 유무'만 되도록 모델 · 말투 · 길이를 맞췄다.
> 판정은 사람이 했다. 자동 지표(인용 수 · 수치 개수)는 보조로만 쓴다.

### 6번 문항을 고친 이유

- v1 질문 "내 생일에 태양은 정말 내 '별자리'에 있었나?"에는 **생일 날짜도, 별자리 기준도 없었다.**
- 보관 결과의 RAG 답도 그 이유를 말했다 — "생일 날짜와 기준으로 삼는 별자리가 제시되지 않아 … 판단할 수 없습니다".
- 즉 v1의 '확인 불가'는 **입력 부족** 때문이었다. 처음 보고서는 이를 '세차 운동 문서가 수집되지 않음'(검색 한계)으로 잘못 설명했다.
- v2는 날짜와 기준을 담은 일반 개념 질문으로 바꿨고, 버전을 올려 v1 결과와 섞이지 않게 했다.

## 4. 무엇이 달랐나

### RAG가 더 나았던 점

1. **검증할 수 있다.** RAG 답의 사실 문장에는 모두 근거 번호가 붙고, 원문 링크로 이어진다. 근거 없이 답한 쪽은 맞아도 확인할 길이 없다.
2. **더 정확하다.** 플레이아데스 빛의 출발 시점은 "16세기 말" → **1587년 무렵**. 아리랑 1호 종료일은 "2008년쯤" → **2008년 2월 20일**.
3. **지금의 값이다.** 보이저 1호의 거리는 질문한 날 JPL Horizons로 계산한 값(2026-10-22 기준 약 258억 km)이다.
4. **모르면 모른다고 한다.** 6 · 7번은 근거에 없는 부분을 "확인되지 않습니다"로 밝히고, 근거로 확인되는 부분만 말했다. 근거 없이 답한 쪽은 7번에 "약 15광년"을 단정했다 — 실제 값에 가깝지만, 서비스 안에서는 확인할 수 없는 수치다.

### 근거 없이 답한 쪽이 나았던 점 (정직한 기록)

- **최신 모델은 근거 없이도 많이 알고 있었다.** 기획 단계에서 예상한 위험("아리랑 1호는 이미 추락했다"고 단정하는 등)은 나타나지 않았다.
- **3번의 '기준에 따라 답이 다르다'는 설명**(태양권계면 vs 오르트 구름)은 근거 없이 답한 쪽만 했다. RAG는 근거 범위 안에서만 답해서, 근거에 없는 관점은 빠진다.
- **6 · 7번은 근거 없이 답한 쪽이 더 '쓸모 있어' 보인다.** 다만 그 내용을 서비스가 보증할 수 없다. VastHorizon의 원칙(지어내지 않는다)상 RAG의 '확인되지 않음'이 맞는 동작이다.

> 결론: RAG의 가치는 이번 비교에서 **정답률보다 신뢰할 수 있는 근거 · 정확한 수치 · 최신 값 · 정직함**으로 드러났다.

## 5. 비교로 찾아 고친 것

| 발견 (보관 실행) | 원인 | 고친 것 |
|---|---|---|
| 5번이 '확인되지 않음' | 별자리 별들의 실제 거리(펼치기 화면의 데이터)가 질의응답 근거에 없었다 | 별자리 질문에 **별 거리표**를 근거로 추가 (`features/extra_evidence.py`, 재색인 없음) — 이번 실행 5번에서 근거로 쓰임 |
| 답 끝에 `⟦END⟧` | 모델이 붙이는 제어 표식이 화면까지 나감 | 명확한 제어 표식만 제거 (`rag/graph.clean_reply`). 원본 응답은 `raw_answer`로 따로 보존 |
| 답 중간에 'એટલે'(구자라트 문자) | 모델이 다른 문자 조각을 섞음 | **근거에 없는 다른 문자가 섞이면 재생성을 요청**한다. 재생성 뒤에도 남으면 답은 그대로 두고 경고를 붙인다. 근거 속 원어 이름 · 직접 인용은 그대로 둔다 |
| 결과 파일의 실행 정보 | 부분 재실행 뒤 최상위 모델 · 시각만 바뀌어 한 번에 실행한 것처럼 보임 | 문항마다 실행 정보(모델 · 검색 · 청킹 · 프롬프트 지문 · 코드 버전), 부분 병합 시 보존, 조건이 섞이면 화면에 경고 |

> 처음에는 다른 문자를 문자권 단위로 지웠다. 근거에서 인용한 원어 이름까지 지워질 수 있어 위처럼 재생성 방식으로 바꿨다.

모두 회귀 테스트가 있다 (`tests/test_rag_compare.py`).
