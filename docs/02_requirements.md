# 02. 요구사항 정의서

> **VastHorizon**: 근거와 함께 세상을 넓혀가는 우주 지식 서비스.
> 이 문서에는 선택한 도메인이 조건을 충족하는 근거와 기능, 비기능 요구사항을 정리했습니다.
> 구현 방법은 [03. RAG 파이프라인 설계문서](03_rag_pipeline_design.md)에서, 충족 여부는 [04. 검증 결과](04_verification.md)에서 확인할 수 있습니다.

## 1. 도메인

| 항목 | 내용 |
|---|---|
| 도메인 | 우주: 천체, 별자리, 인류의 우주 탐사 |
| 서비스 | 3D 하늘에서 천체를 고르고, 근거 문서로만 답하는 질의응답, 특화 기능 |
| 원칙 | **위로를 지어내지 않습니다. 사실로 위로합니다.** |
| 핵심 경험 | 바라본 천체가 멀수록 '내 세상의 반지름'이 지평선(약 4.7km)에서 우주로 넓어집니다 |

### 조건 3: 근거 없이 답하면 틀리기 쉬운 질문 (3개 이상)

| # | 질문 | 근거 없이 답할 때의 위험 |
|:-:|---|---|
| 1 | 아리랑 1호는 지금도 지구를 돌고 있나? | 운용 종료와 궤도 이탈을 혼동하기 쉬움 |
| 2 | 제임스 웹 망원경은 허블처럼 지구를 도나? | 지구 궤도로 착각하기 쉬움 (실제는 L2 부근) |
| 3 | 보이저 1호는 태양계를 벗어났나? | 기준(태양권계면, 오르트 구름)과 '지금' 거리를 놓침 |
| 4 | 지금 보는 플레이아데스의 빛은 언제 출발했나? | 거리 수치를 지어내면 연도까지 틀림 |
| 5 | 오리온자리 별들은 서로 가까이 모여 있나? | "가깝다"고 단정하기 쉬움 (실제 26 ~ 5,285광년) |
| 6 | 점성술의 양자리 날짜에 태양은 실제로 양자리 앞에 있나? | 점성술 날짜를 사실처럼 답함 |
| 7 | 견우성과 직녀성은 실제로 얼마나 떨어져 있나? | 거리 수치를 지어내기 쉬움 |
| 8 | 천상열차분야지도는 무엇을 담은 유물인가? | 제작 연대, 별 개수를 틀리기 쉬움 |

> 이 8개 질문으로 RAG 적용 전후를 비교했습니다: [05. RAG 전후 품질 비교](05_rag_comparison.md).

### 조건 4: 판단이 위험한 도메인인가

- 우주는 건강이나 금융처럼 판단이 위험한 도메인이 **아닙니다**. 그래서 질의응답에는 면책 문구를 두지 않습니다.
- 다만 **관점 전환(마음 한 줄)** 기능은 사용자의 마음을 다루기 때문에 아래와 같은 장치를 둡니다.

| 상황 | 동작 |
|---|---|
| 관점 전환 화면, 모든 응답 | "VastHorizon은 전문 심리상담을 대신하지 않습니다." |
| 위기 표현 (코드 검사 → LLM 2차 확인) | 답변 대신 상담 창구 안내: 자살예방상담전화 **109**, 정신건강위기상담전화 **1577-0199** |
| 위기 여부를 확인하지 못함 | 답변하지 않고 재시도, 감정 버튼, 상담 창구 안내 |

## 3. 기능 요구사항

### 필수 기능 (F2001 ~ F2012)

| 번호 | 분류 | 요구사항 | VastHorizon 구현 |
|---|---|---|---|
| F2001 | 데이터 | 항목 메타데이터 적재 | 424건 로드 → 항목 1건을 그룹별 속성으로 묶은 색인 텍스트 1개 (`data/item_text.py`) |
| F2002 | 색인 | 메타데이터 색인 (RAG 1) | `cosmos_items` 컬렉션, 항목당 1청크, 청크 ID = Wikidata QID (재색인해도 덮어쓰기), 화면 오른쪽 위에 색인 건수 상시 표시 |
| F2003 | 프롬프트 | 검색어 추출 (프롬프트 1) | "천문학 해설사" 역할, JSON `{"queries": [...]}`, 항목 자체 문서는 항상 검색 대상 |
| F2004 | 수집 | 외부 문서 수집 (프롬프트 2) | 위키백과 검색 후보 → 제목, 요약만 보고 선별 → 본문, 원문 URL 수집. 항목 자체 문서(위키, NASA)는 어떤 제외 규칙보다 우선. 수집한 검색어는 캐시 |
| F2005 | 색인 | 외부 문서 색인 (RAG 2) | `cosmos_docs` 컬렉션, 청크 ID `항목ID:문서ID:순번`, 청크 크기, 중복 길이는 `config.toml` |
| F2006 | 검색 | 근거 검색 및 병합 | 항목 메타데이터 청크는 검색 없이 항상 근거 1 + 그 항목 범위의 문서 청크 검색 → 병합, 중복 제거. Top-k는 설정 |
| F2007 | 생성 | 근거 기반 답변 (프롬프트 3) | LangGraph `retrieve → generate` 두 노드, 근거에 출처 유형(항목 메타데이터 / 외부 문서) 구분, 근거가 없으면 "제공된 문서에서는 확인되지 않습니다" |
| F2008 | 생성 | 근거 표시 | `[근거 N]` 표기에서 실제 인용된 근거만 제목, 원문 링크와 함께 표시, 인용이 없으면 "이 답변에는 인용된 근거가 없습니다." |
| F2009 | UI | 항목 선택 및 질의응답 | 3D 하늘에서 누르기, 천체 목록(검색, 그룹 필터)에서 고르기, 항목별 대화 기록 분리 |
| F2010 | 서비스 | 도메인 특화 기능 | **빛의 편지**, **별자리 펼치기**, **오늘 밤 나의 하늘**, **관점 전환**: 모두 근거 인용 (아래 표) |
| F2011 | 서비스 | 조건 기반 항목 탐색 | 자연어 조건 → 메타데이터 필터 + 의미 검색 → LLM 선별 → 카드 → 누르면 그 천체의 대화로. 특정 천체에 대한 사실 질문("안드로메다 은하 가운데 블랙홀 이름은?")이면 검색하지 않고 그 천체에게 같은 질문을 보내는 버튼을 보여 줍니다 |
| F2012 | UI | 진행 상태 및 안내 | 수집, 색인, 답변 단계 표시, 색인 없음 / 키 누락 안내 띠, 관점 전환 면책 안내 |

### 도메인 특화 기능 (F2010)

| 기능 | 하는 일 | 근거 |
|---|---|---|
| 빛의 편지 | "지금 당신에게 닿은 이 빛이 출발했을 때, 지구에서는…": 빛의 출발 연도와 그 해의 사건 | 항목 메타데이터(거리) + 그 해의 한국어 위키 연도 문서 |

| 오늘 밤 나의 하늘 | 내 위치, 시각의 하늘에서 찾을 별자리, 행성 안내 | 하늘 위치 계산표 + 별자리 항목 정보 |
| 관점 전환 | 마음 한 줄 곁에 우주의 사실 하나 | 관점 전환 서가(위키 문서 13개), 위기 안내 우선 |

### 그 밖의 추가 기능

| 기능 | 내용 |
|---|---|
| 실시간 위치 근거 | 태양계 천체, 심우주 탐사선은 질문한 날의 위치를 JPL Horizons로 계산해 근거에 추가 |
| 프롤로그 | 처음 켰을 때 8개 장면으로, 세상이 좁게 느껴지는 날에 건네는 우주의 사실 (지평선 4.7km, 안드로메다의 빛, 항성 핵합성, 벨 부등식과 2022년 노벨 물리학상, 가속 팽창, 관측 가능한 우주). 사실을 말하는 장면은 모두 출처를 함께 보여 줍니다 |
| 천체 소개 | 천체를 고르면 자체 위키 문서의 첫머리, 역사 절을 먼저 보여 주고, 다 읽은 뒤 '내 세상에 담기' |
| 실제 하늘 | 화면의 모든 점이 실제 천체입니다. 히파르코스 별 118,216개(확대하면 12등급대까지), 성운과 성단과 은하 15,809개, 은하수 (d3-celestial) |
| 아무 별이나 | 하늘의 어떤 별을 눌러도 히파르코스 번호로 Wikidata에서 거리와 이름을 조회해 그 별 자체로 담고 물어볼 수 있습니다. 거리가 없거나 어느 별인지 모호하면 거리를 지어내지 않고 지도에도 놓지 않으며, '거리 미확인'으로 알아간 빛 기록에만 남길 수 있습니다 |
| 넓어지는 실감 | 내 세상은 내가 알아간(담은) 천체입니다. 지도에서는 네온 분필과 이름, 나에서 이어지는 빛의 선으로 보여 주고, 천체 둘레에 영역(구)은 그리지 않습니다. 거리 안에 있어도 아직 알아가지 않은 천체는 흐리게 일렁입니다. 이것은 개인의 배움에 대한 은유이며, 천체의 물리적 상태가 정해지지 않았다는 주장이 아닙니다. 알아간 기록은 날마다 지워지지 않고 쌓이며(오늘 새로 알아간 수는 따로 표시), 지우기는 사람이 직접 고를 때만 합니다. 가까운 천체든 먼 천체든 담을 때마다 '새로운 빛 하나가 더해졌다'고 알리고, 더 멀리 닿았을 때만 닿은 거리를 덧붙입니다. 내 세상 보기는 처음 한 번만 우주 끝까지 떠오르고, 그 뒤에는 마지막에 보던 자리로 바로 엽니다. 지도 고리(1광년, 1천 광년, 100만 광년, 관측 가능한 우주의 끝)는 멀수록 간격이 넓어지고, 최대로 물러나면 우주의 끝 전체가 보입니다. '내 세상' 카드는 기본으로 알아간 빛, 가장 먼 빛, 최근 알아간 천체만 보여 주고, 크기 비교(빛으로 걸리는 시간, 1mm 모래알 모형, 부피 비)와 알아간 빛 기록은 펼쳐서 봅니다 (계산만, 기준값 출처 표기) |
| 몽환적 표현 | 남보라 밤하늘 팔레트를 씁니다. 담은 천체는 네온 분필 오로라와 성운 빛무리로 그리고, 담는 순간 그 천체가 환하게 켜집니다. 가장 먼 빛까지는 청록, 보라, 분홍의 옅은 테두리만 그립니다. 이미지 파일 없이 코드로 그립니다 |
| 선택 표시 | 고른 천체를 오늘 밤 하늘과 내 세상 보기에서 맥박 치는 고리와 이름으로 표시합니다 |
| 태양, 달, 행성 | 그날의 위치를 브라우저에서 계산해(JPL 근사 궤도 요소, 천문 연감 달 식) 실제 시지름과 실제 태양 방향의 빛으로 그립니다. 달은 NASA 표면 지도로, 위상이 저절로 맞습니다. 행성 표면은 사진이 아니라 색과 띠를 단순화한 그림입니다 |
| 메시에 사진 | 메시에 천체 89개의 NASA 허블 메시에 목록 사진을 서랍에 출처 표기와 함께 보여 주고, 하늘에서 확대하면 그 자리에 띄웁니다 |
