## 2. 문서 수집과 색인 (F2003 ~ F2005)

질문: **"제임스 웹은 어떤 빛으로 우주를 관측하나?"** (항목 제임스 웹 우주망원경)

| 확인 | 결과 | 판정 |
|---|---|:-:|
| 프롬프트 ①의 검색어 | `제임스 웹 우주망원경`(항목 이름), `적외선`, `근적외선`, `중적외선` | 통과 |
| 색인된 문서와 버려진 문서 구분 | 아래 판정 기록: 색인 2, 기존 연결 3, 제외 10 (각 사유 기록) | 통과 |
| 같은 질문을 다시 물으면 수집 안 함 | 두 번째: 검색어 재사용, 위키 검색 호출 0, LLM 호출 0, 새 문서 0 | 통과 |
| 항목 자체 문서가 빠지지 않음 | "제임스 웹 우주망원경" 위키, NASA NSSDCA 문서 모두 연결. 선별 프롬프트와 무관하게 강제 포함 | 통과 |
| 청크 크기, 겹침을 바꾸면 청크 수가 달라짐 | 같은 문서 8건(81,417자): 500/100 → 253, 1000/200 → 123, 2000/400 → 64 | 통과 |

판정 기록 (처음 수집, 발췌)

```text
[색인] 제임스 웹 우주망원경 — 항목 자체 문서 — 선별 규칙보다 우선
[기존] 우주망원경 · 허블 우주망원경 · 망원경 — 이미 연결된 문서
[제외] 제임스 웹 우주망원경 최초의 딥 필드 — 선별 프롬프트에서 제외
[색인] 적외선 — 선별됨
[제외] 열화상 · 적외선 분광법 · 적외선 온도계 · 적외선 사진술 — 선별 프롬프트에서 제외
[제외] 근적외선 분광법 · 근적외선 카메라 및 다중 표적 분광기 · 스피어X — 선별 프롬프트에서 제외
[제외] 적외선 검출기 · 발광적외선은하 — 선별 프롬프트에서 제외
… 수집 완료 — 새 문서 1건, 연결 문서 8건
```

청크 수 전체 표와 판단 근거는 [03 §4](03_rag_pipeline_design.md#4-청킹)에 있습니다.
