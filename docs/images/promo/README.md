## 제작 기준

- 실제 서비스의 ‘오늘의 하늘’, ‘내 세계’, 읽기 카드 화면을 색감과 형태의 기준으로 삼았습니다.
- 공통 색: 남보라 `#272B61`, 푸른 보라 `#5960A1`, 라벤더 `#8C68AC`, 청록 안개 `#63A9C9`, 살구색 리본 `#F3DAD5`, 종이색 `#FFF9F3`.
- 하늘 그라데이션, 가는 별자리 선과 점선 원, 하단 살구색 리본, 한글 명조체를 사용했습니다.
- 2번 카드의 채운 복숭아빛 별은 ‘내 세계’에 저장한 천체, 빈 원은 아직 발견하지 않은 천체를 뜻합니다.
- 3번 카드는 특정 천체에 대한 검증되지 않은 사실이나 출처를 이미지에 넣지 않고, 지식에 기반한 위로라는 원칙을 시각화했습니다.
- 내장 `image_gen` 도구로 각 카드의 문구와 장면을 지정해 개별 제작했습니다.
