# VastHorizon 디자인 적용 명세

이 문서는 Claude 에이전트에게 전달할 시각·상호작용 기준을 정리합니다. [클릭 시안](index.html)과 [첫 하늘](previews/01-discover.png), [빛을 읽다](previews/02-read.png), [내 세계](previews/03-collect.png), [모바일 내 세계](previews/05-mobile-collect.png)를 함께 참고하세요. `design-proposal/`은 실제 앱과 연결되지 않은 독립 시안입니다.

## 1. 핵심 방향

- 중심 문장: **빛 하나를 알아갈 때, 내 세계도 조금 넓어진다.** 천체의 물리적 상태를 사람이 결정한다는 뜻이 아니라 배움의 은유입니다.
- 기존 프롤로그 뒤 경험을 **첫 하늘 → 빛을 읽다 → 내 세계에 담다** 순서로 정리합니다.
- 첫 화면은 문장 하나와 주 행동 하나에 집중합니다. 자세한 정보는 천체를 고른 뒤에 펼쳐 보여 줍니다.
- 분위기는 ‘차가운 우주 계기판’보다 ‘밤하늘 위에 놓인 편지’에 가깝습니다. 별의 밀도와 여백을 번갈아 배치합니다.

## 2. 색상 팔레트

| 역할 | 색상 | 사용 위치 |
| --- | --- | --- |
| 깊은 남보라 | `#222454` | 하늘의 어두운 바탕 |
| 푸른 보라 | `#555DA3` | 하늘 그라데이션의 중간 |
| 흐린 자주빛 | `#9970AF` | 먼 하늘, 성운 같은 색 번짐 |
| 옅은 청록 | `#63A9C9` | 하단 지평선의 빛 번짐 |
| 살구빛 | `#F3DAD5` | 주요 버튼, 하단 리본, 알아간 천체의 채운 표식 |
| 종이색 | `#FFFAF5` | 정보 카드와 편지 같은 면 |
| 밝은 카드색 | `#FFF9F3` | 읽기 카드의 실제 시안 배경 |
| 본문 남보라 | `#282345` | 밝은 면 위의 제목과 본문 |
| 보조 글자 | `#686274` | 밝은 면 위 설명 |
| 강조 보라 | `#8D67A1` | 핵심 숫자와 문장 일부 |

메인 하늘은 단색이 아니라 `#272B61 → #5960A1 → #8C68AC`의 완만한 그라데이션입니다. 오른쪽 상단과 중단에는 흐린 자주빛, 왼쪽 하단에는 청록빛을 낮은 불투명도로 얹습니다. 시안의 정확한 레이어 값은 [style.css](style.css)의 `.sky-surface`를 참고하세요. 텍스트와 카드 뒤에는 어두운 그라데이션을 얇게 깔아 글이 잘 읽히게 합니다.

살구색은 주 행동과 **이미 알아간 빛**에 집중해서 사용합니다. 별·선·카드 전체에 같은 강도의 광채를 주지 않습니다.

## 3. 폰트와 글자 위계

시안의 CSS 스택은 다음과 같습니다. 시안 자체는 웹폰트를 내려받지 않으므로 운영체제에 따라 실제 서체가 달라집니다.

```css
--serif: Georgia, "Noto Serif KR", "AppleMyungjo", serif;
--sans: -apple-system, BlinkMacSystemFont, "Apple SD Gothic Neo", "Noto Sans KR", sans-serif;
```

**실제 앱 적용 시에는 이미 불러오는 `Noto Serif KR`을 제목과 큰 거리 숫자에, `Pretendard Variable`을 본문·버튼·출처에 사용하세요.** 두 서체는 [web/tokens/fonts.css](../web/tokens/fonts.css)에 이미 정의돼 있습니다. 라틴어 워드마크의 기울임은 시안의 `Georgia` 느낌을 참고해 선택적으로 표현합니다.

| 역할 | 시안 기준 |
| --- | --- |
| 첫 하늘의 큰 제목 | 명조, 보통 굵기 400, `clamp(38px, 4.1vw, 74px)`, 행간 1.22, 자간 `-0.055em` |
| 장면 제목 | 명조 31–55px, 행간 1.35, 자간 약 `-0.06em` |
| 천체 카드 제목 | 명조 `clamp(26px, 2.5vw, 42px)`, 보통 굵기 |
| 핵심 사실 문장 | 명조 `clamp(20px, 2.15vw, 33px)`, 행간 1.5; 핵심 숫자만 보라색 |
| 본문 | 고딕 13–14px, 행간 1.8–1.85; 실제 앱에서는 현재의 15px 본문 토큰을 우선 활용 |
| 눈썹 문구·출처 | 고딕 10–11px, 자간 0.15–0.25em; 실제 앱의 작은 글자는 모바일에서 12px 이상으로 조정 |

제목은 길게 설명하지 않고 2–3행의 짧은 문장으로 둡니다. 살구색이나 흐린 보라로는 제목의 한 구절이나 숫자 하나 정도만 강조합니다. 근거와 설명에는 장식적인 자간을 쓰지 않습니다.

## 4. 장면별 구성

| 장면 | 시각 구성 | 핵심 행동 |
| --- | --- | --- |
| 첫 하늘 | 왼쪽 약 절반에 큰 명조 문장, 오른쪽에 선택 가능한 천체. 하단 137px 살구색 리본에 내 세계의 현재 거리. 데스크톱 상단 탐색은 간결하게. | `첫 번째 빛 만나기` |
| 빛을 읽다 | 왼쪽 하늘·천체 사진, 오른쪽 너비 약 37%의 종이색 카드. **짧은 사실 → 설명 → 출처 → 담기** 순서. | `이 빛을 내 세계에 담기` |
| 내 세계 | 밤하늘 위에 내가 알아간 빛의 지도, 왼쪽 설명과 범례, 오른쪽 요약 카드. 가장 먼 빛과 알아간 수가 먼저 보이게. | 알아간 빛 확인, 다음 천체로 이동 |

카드와 주 버튼은 각진 종이 조각에 가깝게 둡니다. 둥근 모서리는 작은 상태 표식과 선택 고리에만 씁니다. 얇은 선과 충분한 여백으로 내용을 나눕니다. 실제 천체 사진은 기존 자산을 사용하고 출처를 계속 표시합니다.

## 5. 알아간 천체의 상태 표시

| 상태 | 표식과 연결 | 이름 |
| --- | --- | --- |
| 알아감 | 지름 약 25px의 살구색 채운 원 안에 `✦`, 약한 후광, `나`와 실선 `#FFE1DD`으로 연결 | 어두운 남보라 이름표 표시 |
| 아직 만나지 않음 | 지름 약 16px의 빈 점선 원, 연결선 없음 | 기본 지도에서는 숨기고 탐색 시 표시 가능 |
| 현재 선택 | 알아간 표식의 바깥에 흰색 1px 고리 추가 | 선택한 천체 카드와 이름을 일치시킴 |

지도에 **알아간 빛 / 아직 만나지 않은 빛** 범례를 둡니다. 색뿐 아니라 채움, 윤곽, 선, 이름표로 상태를 구분합니다. 알아간 천체가 많아지면 채운 표식은 그대로 두고, 이름표와 선은 겹침을 줄이거나 선택한 천체의 것을 우선해 보여 줍니다. 같은 상태 표식을 하늘, 검색 결과, 천체 서랍, 내 세계에 일관되게 적용하고, 천체를 담거나 지운 직후에는 모든 화면을 갱신합니다. 모바일 시안의 표식은 채운 원 20px, 빈 원 13px이지만 실제 터치 영역은 최소 44×44px로 확보합니다.

현재 앱에는 `web/js/main.js`의 `world.visited`, `isObserved`, `state.sky?.setObserved(...)`, `state.map?.setWorld(...)` 흐름이 있습니다. 이 상태를 그대로 사용하면 별도의 저장 방식이 필요하지 않습니다.

## 6. 반응형과 움직임

- 데스크톱 시안은 1440×900 비율을 기준으로 만들었습니다.
- 너비 1000px 이하에서는 글과 카드의 크기를 줄입니다. 650px 이하에서는 상단 보조 메뉴를 접고, 읽기 카드를 화면 하단 전폭으로 배치합니다. ‘내 세계’ 요약 카드도 하단 전폭으로 옮깁니다.
- 장면은 약 350ms 동안 투명도를 바꾸며 전환하고, 별에 호버하면 약 200ms 동안 크기가 조금 변합니다. `prefers-reduced-motion`이 켜져 있으면 움직임을 생략합니다.
- 3D 하늘의 실제 천체와 조작은 기존 구현을 사용합니다. 시안의 무작위 배경 별은 화면 분위기를 보여 주기 위한 것입니다.

## 7. 실제 앱에 적용할 때

- 토큰은 기존 [색상](../web/tokens/colors.css)·[폰트](../web/tokens/fonts.css)·[타이포그래피](../web/tokens/typography.css) 파일을 확장하거나 조정합니다. 화면별 스타일은 [web/style.css](../web/style.css)에 연결합니다.
- 프롤로그의 장면 구조와 기존 기능은 유지하며, 프롤로그가 끝나는 순간 첫 하늘 시안의 시선 흐름으로 이어지게 합니다.
- RAG 답변, 문장별 출처, 확인 불가 안내, 위기 안내, 실제 하늘·거리 계산을 유지합니다. 짧은 사실은 근거가 있는 문장으로만 표시합니다.
- 시안의 데모 수치·문구·3개 저장 예시는 실제 앱 상태와 데이터로 바꿉니다.
